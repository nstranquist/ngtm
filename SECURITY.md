# Security

Nicos GTM is a local CLI. It does not require an account. Do not put live
API tokens, cookies, or private launch ledgers into issues, fixtures, or
pull requests.

Please do not disclose security issues in a public issue.

Use GitHub's private vulnerability reporting for this repository. If it is
unavailable, contact [@nstranquist](https://github.com/nstranquist) privately
before public disclosure.
