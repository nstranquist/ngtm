Nicos GTM

A local go-to-market factory that pairs live feeds with an LLM and tags every claim grounded, inferred, or speculative. It will not invent a Show HN URL.

launch ledger provenance SEO research MIT

Install (public clone-and-run)

The engine ships from the public nicos-tools repository. You do not need this identity checkout to build or run the CLI.

git clone https://github.com/nstranquist/nicos-tools.git
cd nicos-tools/nicos-dev
go build -o "$HOME/.local/bin/ngtm" ./cmd/ngtm
ngtm version
ngtm --json feeds

Same engine via ndev gtm once ndev is on your PATH.

What it does

  • Channel-native drafts (Show HN, X, Reddit, …) with [FILL:] instead of invented facts
  • Weekly launch cohorts: plan → kit → posted receipt → measured verdict
  • SEO research that stays empty on volume unless a cheap labs key is set
  • Brand / landing / design / economics as the same dispatcher

Name

Public name is Nicos GTM. Short name and binary are ngtm. Do not launch it as bare “ngtm” — that token is a teachers’ movement and an airport code.

MCP

ngtm mcp exposes analysis and read-only launch tools. Ledger writes (plan, posted, signal, import) stay on the CLI.
