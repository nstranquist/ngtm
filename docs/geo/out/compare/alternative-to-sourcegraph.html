Sourcegraph alternative: docs-puller

Draft. noindex. Last verified 2026-08-19T21:43:19Z.

docs-puller copies vendor, reference, and local project docs into Markdown, builds a local SQLite FTS5 index, and searches that index on the operator's machine. Retrieval quality is measured with checked-in evaluations.

When to pick each

  • docs-puller — Pull vendor and project docs into a local Markdown corpus
  • Sourcegraph — see that product's own docs. This draft does not evaluate it.
